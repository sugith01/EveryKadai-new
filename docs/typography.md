# Typography Specifications: Vyapar App

## 1. Font Family
- **Primary Font Family:** `Poppins, sans-serif`
- **Fallback Stack:** `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- **Font Provider:** Google Fonts (`weights: 400, 500, 600, 700, 800`)

## 2. Type Hierarchy

### Display & Hero Heading
- **Tag:** `<h1>`
- **Selector:** `.vyh-hero__heading`
- **Font Size:** `50px` (Desktop) / `32px` (Mobile)
- **Font Weight:** `700` (Bold)
- **Line Height:** `57.5px` (1.15)
- **Letter Spacing:** `-0.02em`
- **Color:** `#111111` (`rgb(17, 17, 17)`)
- **Margin:** `50px 0 25px 0`

### Section Main Heading
- **Tag:** `<h2>`
- **Selector:** `.vyh-journey h2`, `.vyh-feat h2`, `.wp-block-heading`
- **Font Size:** `38px` (Desktop) / `24px` - `28px` (Mobile)
- **Font Weight:** `800` (Extra Bold)
- **Line Height:** `45.6px` (1.2)
- **Letter Spacing:** `-0.01em`
- **Color:** `#111111`
- **Margin:** `45px 0 19px 0`

### Section Sub-Heading / Section Intro
- **Tag:** `<p>`
- **Selector:** `.vyh-hero__subtext`, `.vyh-faq__subtext`
- **Font Size:** `16px`
- **Font Weight:** `400` (Regular)
- **Line Height:** `26.4px` (1.65)
- **Color:** `#444444` (`rgb(68, 68, 68)`)

### Card Headings
- **Tag:** `<h3>` / `<h4>`
- **Selector:** `.vyh-feat__item-title`, `.vyh-who__card-title`
- **Font Size:** `20px` - `22px`
- **Font Weight:** `600` (Semi Bold)
- **Line Height:** `28px`
- **Color:** `#111111`

### Body Copy
- **Tag:** `<p>`, `<li>`, `span`
- **Font Size:** `16px`
- **Font Weight:** `400`
- **Line Height:** `26.88px` (1.68)
- **Color:** `#000000` / `#444444`

### Action & Button Typography
- **Primary Hero Button:** `20px`, Weight `700`, Line-height `33.6px`, Color `#ffffff`
- **Standard Button:** `16px`, Weight `600`, Line-height `24px`
- **Navigation Links:** `16px`, Weight `400` - `500`, Line-height `20px`, Color `#9d9d9d` (hover `#ed1a3b`)

### Small Text & Meta Badges
- **Tag:** `<small>`, `.badge`, `.caption`
- **Font Size:** `13px` - `14px`
- **Font Weight:** `500` - `600`
- **Line Height:** `18px`
